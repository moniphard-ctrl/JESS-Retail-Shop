# JESS RETAIL SHOP MANAGEMENT INFORMATION SYSTEM

## 1. Introduction
JESS Retail Shop Management Information System is a web-based system developed to improve the management of daily retail shop activities.

The system helps manage products, sales, customers, suppliers, users and business reports.

## 2. Problem Statement
JESS Retail Shop initially used manual records to manage its operations. This made it difficult to track stock, monitor sales and maintain accurate business records.

The proposed system provides a computerized solution to these challenges.

## 3. Objectives
- To computerize sales transactions.
- To manage products and inventory.
- To maintain customer and supplier records.
- To manage system users.
- To generate management reports.
- To improve accuracy and efficiency.

## 4. Technologies Used
- HTML
- PHP
- MySQL
- XAMPP
- phpMyAdmin

## 5. System Modules
1. Dashboard
2. Category Management
3. Product Management
4. Customer Management
5. Supplier Management
6. User Management
7. Sales and Receipts
8. Reports

## 6. Database
Database name: jess retail shop

The database contains nine tables:
- users
- categories
- products
- customers
- suppliers
- sales
- sale_items
- purchases
- purchase_items

## 7. Installation
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into htdocs.
4. Import jess_retail_shop.sql through phpMyAdmin.
5. Configure the database connection in the PHP files.
6. Open http://localhost/jess/ in a browser.
